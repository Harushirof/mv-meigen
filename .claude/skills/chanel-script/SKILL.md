# シャネル動画 ① 台本づくり

TikTok「偉人のひとり言」（@ijin_hitorigoto_coco）向けに、ココ・シャネルが語りかける約1分40秒の縦型動画の台本を作る。
出来上がった台本は、次に `chanel-voice`（音声）→ `chanel-render`（字幕動画とサムネ）の順で使う。

お手本は1本目 `chanel/posts/01_erabareru-onna/`。迷ったら必ずこれを読んで、長さ・文体・区切り方を合わせる。

## 入力
- テーマ（指定がなければ、シャネルの人物像に合う人生訓を3案出して選んでもらう）
- 番号とスラッグ（指定がなければ `chanel/posts/` の最大番号＋1、スラッグはタイトルのローマ字を短く。例 `02_jibun-no-iro`）

## 出力（`chanel/posts/NN_スラッグ/` に作る。すべて Git に上げてよい）
| ファイル | 中身 |
|---|---|
| `narration.txt` | 読み上げ全文。1行目はタイトルだけ |
| `telop.txt` | 字幕の区切り。1行＝1文 |
| `caption.md` | 投稿文（TikTok・Facebook共通） |
| `config.json` | 動画の設定。1本目の config.json をコピーし、`title_lines` と `output` だけ変える |

## 進め方
1. 1本目の `narration.txt`、`telop.txt`、`caption.md`、`config.json` を読む。
2. タイトルを「AよりBな女になりなさい」「〜しなさい」型の一文にする。対比があること。15〜25文字。
3. 本文を下の構成で書く。
4. `telop.txt` を作る。
5. `caption.md` と `config.json` を作る。
6. チェックリストで確認し、タイトルと本文を依頼者に見せて OK をもらう（音声づくりは文字数に応じて料金がかかるので、OK の前に進まない）。

## 本文の構成（全体 500〜550文字 ≒ 1分40秒）
1. タイトルをそのまま読む
2. 「いい？」で呼びかけ → よくある考え方を具体的に並べる →「でもね、私に言わせれば」で言い切る
3. 「〜というのは、〜じゃない。〜かどうかよ」で本質を定義する
4. シャネル自身の人生の事実を短文で（孤児院、帽子店、ジャージー素材、リトルブラックドレス、香水、70歳での復帰など。年号や事実は確かなものだけ）
5. 「ただし、覚えておいて」で、自分側の覚悟・責任へ一段深める
6. 「ところが」で反対側の女性像と、その行き着く先
7. 「だから」で命令形の行動指針を2〜3個（「〜しなさい」「〜はやめなさい」）。今日すぐできる具体的な行動を1つ入れる
8. 「〜は、〜じゃない。〜もの。それが私の〜よ」型の短い3文で締める

## 文体のルール
- 一人称は「私」。語尾は「〜よ」「〜わ」「〜なの」「〜なさい」「〜じゃない」。上品で、少し突き放す大人の女性の口調。
- 1文は短く。長くても45文字程度。「。」で文を区切る（音声は「。」ごとに作り、文の間に0.6秒の間が入る）。
- 「？」で終わる呼びかけは、次の文とつなげて1文にする（例「いい？　誰かに〜いる。」）。
- 本人の実際の発言だと断定する表現は書かない（「〜と語った」「シャネルの名言」など）。
- 服、帽子、香水、鏡、真珠、黒いドレスのような具体物を必ず入れる。

## telop.txt のルール
- 1行目に注記行 `# 1行＝音声の1文。テロップの区切りは全角スペース、縦書きの列の折り返しは「/」。1行目はタイトル表示なので無視される。` を書く。
- 2行目以降、narration.txt の「。」で区切った1文を1行にする（行数＝文の数。合わないと音声・動画づくりで止まる）。
- 1枚の字幕は8〜16文字。全角スペースで区切る。意味の切れ目で切り、助詞の途中では切らない。
- 1枚が11文字以上になるときは「/」で縦の列を2列に折り返す（例 `選ばれるのを/待つ人生ほど`）。1列は10文字まで。
- 句読点（、。？！）は入れない。

## caption.md
1本目と同じ形にする：見出し `# NN タイトル — 投稿文（TikTok・Facebook共通）`、コードブロックの中にタイトル → 本文の要約2〜3行 → 今日できる行動の一言 → `※ココ・シャネルの生き方をもとにした創作の独り言です。本人の発言ではありません。` → ハッシュタグ5個（#ココシャネル #名言 #生き方 ほか）。最後に「投稿時: AI生成ラベルをオン。」

## config.json
- `title_lines`：タイトルを縦3列に分ける（1列7文字前後、意味の切れ目で）。句読点は入れない。
- `output`：`chanelNN_ShinshiiAsa.mp4`（BGMを変えるときは曲名を変える）
- 他（背景 `../../../reels/chanel_common/background.png`、明るさ0.6、字幕の位置0.68、しっぽり明朝、影）は1本目のまま変えない。

## チェックリスト
- [ ] 本文が500〜550文字（空白を除く）
- [ ] タイトルの対比が冒頭・中盤・締めで出ている
- [ ] シャネル自身の事実が入っていて、年号などが正しい
- [ ] 本人の発言だと誤解させる表現がない
- [ ] telop.txt の行数（注記行を除く）が narration.txt の文の数と同じ
- [ ] telop.txt に句読点が残っていない
