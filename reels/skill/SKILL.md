# 偉人の語りリール 台本づくり

Facebookページ「偉人の手帳」のリール台本を作る。白黒の偉人写真の上に、ナレーションと同じ文言の縦書きテロップを1フレーズずつ出す形式。台本1本から、音声とテロップの両方を作る。

## 入力
- 偉人の名前（指定がなければ候補を3つ出して1つ選ぶ）
- テーマ（指定がなければ、その偉人の人物像と合う人生訓を3案出して1つ選ぶ）

## 進め方
1. 偉人の人物像を確認する：生没年、代表的な実績、知られている口調・逸話。生没年は確実なものだけを書く。
2. テーマを「AよりBを持て／Aするな、Bしろ」型の一文タイトルにする。15〜25文字。対比があること。
3. 下の9パート構成で本文を書く。
4. テロップ分割を作る。
5. 投稿文を作る。
6. 最後にチェックリストで確認する。

## 9パート構成（全体 約1,800文字 ≒ 5分半）
| # | 役割 | 文字数の目安 |
|---|---|---|
| 1 | タイトルをそのまま読み上げる（つかみ） | タイトル分 |
| 2 | 「いいか」で呼びかけ → よくある考えを具体的なセリフで並べて否定 →「だがな、俺から言わせれば」で言い切る | 200 |
| 3 | 本質を「〜というのは、〜じゃない。〜でもない。〜かどうかだ」で定義 → 調子がいい時と苦しい時の対比 → 苦境を短文で畳みかける →「それじゃ〜とは言えん」→ 反対の良い例 | 450 |
| 4 | 「ただしな、ここで大事なことがある」で教訓を一段深める（受け身でなく自分側の責任へ）→「ここを間違えちゃいかん」 | 200 |
| 5 | 「例えば」で始まる具体的なエピソード（人物・年数・セリフ入り）→ 二択の問い →「こういうところで〜が決まる」→ できなくてもいいこと／それでもできること → 一文の格言 | 300 |
| 6 | 「ところがな」で反対側の人間像 → その末路を短文で畳みかける →「その時になって初めて分かる」 | 250 |
| 7 | 「人生の後半になればなるほど」で時間軸を足す → 若い頃との対比 →「最後に残るのは〜じゃない。〜だ」 | 150 |
| 8 | 「だから」→ 命令形の行動指針を6〜8個（〜しろ／〜するな） →「そういう積み重ねが10年後、20年後に〜になる」 | 150 |
| 9 | もう一度「いいか」→ タイトルの言い直し（条件を列挙）→「〜じゃない。〜だ」→ 最後は「〜じゃない。〜だ。それが現実だ」型の短い3文で締める | 250 |

## 文体のルール
- 一人称は「俺」。語尾は「〜だ」「〜じゃない」「〜しろ」「〜するな」「〜もんだ」「〜とは言えん」。
- 呼びかけ・つなぎ語を節目に使う：「いいか」「だがな」「人間というのはな」「ところがな」「ただしな」「だから」。
- 1文は短く。長くても40文字程度。具体的なセリフは「」で入れる。
- 抽象語だけで終わらせない。必ず名刺、電話帳、肩書、夜中の2時のような具体物・具体的な場面を入れる。
- 偉人本人の実際の発言だと断定する表現は書かない（「〜と語った」「〜の名言」など）。

## テロップ分割のルール
- ナレーションと同じ文言を、1枚8〜16文字程度で区切る（縦書き1行〜2行）。
- 意味の切れ目で区切る。助詞の途中では切らない。
- 冒頭タイトルだけは3行・3色（黄・赤・緑）の強調表示にする。
- 句読点はテロップに入れない。

## 投稿文
- 1行目：`偉人名「タイトル」`
- 2行目：`※偉人の人物像をもとにした創作です`
- その後：ハッシュタグ3〜5個（#偉人の手帳 #名言 #人生訓 など）

## 出力形式
1. 偉人名・生没年・タイトル
2. 本文（9パートの見出しつき）
3. テロップ分割（1行1枚）
4. 投稿文
5. 文字数と推定尺（1秒あたり5.7文字で計算）

## チェックリスト
- [ ] 本文が1,600〜2,000文字に収まっている
- [ ] タイトルの対比が冒頭・パート2・パート9で3回出ている
- [ ] 「ただしな」の深掘りで、教訓が自分側の行動に向いている
- [ ] 具体的なエピソードにセリフと年数が入っている
- [ ] 本人の実際の発言だと誤解させる表現がない
- [ ] 生没年が正しい
